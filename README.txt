BULBROWSER — интерактивный сатирический псевдобраузер

Запуск: откройте index.html в обычном браузере. Интернет не нужен для основной функциональности. Внешний шрифт при отсутствии сети заменится системным.

Публичная ссылка: загрузите ВСЮ папку BULBROWSER на хостинг статических сайтов (например, Netlify Drop: https://app.netlify.com/drop). Сервис выдаст публичный URL, которым можно поделиться с кем угодно. При загрузке файла отдельно изображения и скрипты не заработают: нужен весь комплект. Можно также загрузить ZIP, если площадка поддерживает ZIP.

Что работает:
- Псевдовкладки, назад/вперёд, обновление, закладки, история.
- Внутренние адреса bul:// и поиск по одобренным страницам.
- Виртуальная блокировка обычных внешних адресов.
- Баланс BulCoin, награды, местный журнал действий, сохранение в localStorage.
- Новости, BulTube, Картофелопедия, БульбаМаркет, каталог и POTATOPEEL.
- Раздел «Враги народа» с переданным изображением.
- Адаптивная верстка для смартфона и компьютера.

ВАЖНО: это сатирическая игра, а не настоящий браузер. Нет реального мониторинга, политической базы данных, денежных средств, фильтрации внешнего трафика или реального контента для взрослых. Все достижения и показатели выдуманы.
